# FacilitaSaude-Platform

Plataforma inteligente de saúde desenvolvida em Django, com foco em organização, IA e conteúdo educativo.

## Estado atual
O repositório contém um scaffold Django inicial com um único app `apps.accounts`. Não existem implementações funcionais de módulos planejados como enciclopédia, nutrição, exercícios, saúde mental, IA ou dashboard.

## Como começar
1. Crie um ambiente virtual Python.
2. Instale dependências:
   ```bash
   pip install -r backend/requirements/base.txt
   ```
3. Execute o servidor:
   ```bash
   cd backend
   python manage.py runserver
   ```

## Observações
Este projeto necessita de trabalho inicial de arquitetura, configuração de ambiente, implementação do app `accounts` e montagem dos módulos planejados.
