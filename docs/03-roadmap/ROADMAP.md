# Roadmap do Projeto FacilitaSaúde

## Visão geral
O roadmap define os marcos de implementação para transformar o scaffold atual em uma plataforma de saúde modular e escalável.

## Sprints previstas
- Sprint 1: Base de projeto e configuração segura.
- Sprint 2: Usuários e autenticação.
- Sprint 3: Enciclopédia de saúde.
- Sprint 4: Nutrição, exercícios e dashboard.
- Sprint 5: IA, saúde mental e recursos premium.

## Recomendação
A prioridade inicial deve ser estabilizar a plataforma base (configuração, autenticação, banco e estrutura de apps) antes de avançar para os módulos de conteúdo e IA.
