# Modelo do Banco de Dados - FacilitaSaúde

## Objetivo

O banco de dados do FacilitaSaúde foi projetado para ser modular, organizado e escalável. Cada módulo representa uma área do sistema e possui suas próprias entidades e relacionamentos.

---

# Estrutura Geral

O banco será dividido nos seguintes módulos:

- 👤 Usuários
- 📖 Enciclopédia
- 🍎 Nutrição
- 🏋️ Treinos
- 🧠 Saúde Mental
- 🚑 Emergências
- 🤖 IA
- 📊 Dashboard

---

# Ordem de Desenvolvimento

Os módulos serão modelados na seguinte sequência:

1. Usuários
2. Enciclopédia
3. Nutrição
4. Treinos
5. Saúde Mental
6. Emergências
7. IA
8. Dashboard
